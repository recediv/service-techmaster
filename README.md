# ТехМастер — просмотр Томска

Сайт на Next.js и React с одним фиксированным городом: Томск. Сохраняются весь каталог, тексты, цены, изображения, консультации и отзывы. Исходная БД, приватные заказы, личные контакты авторов и рабочие отладочные материалы в репозиторий не входят.

Нужен Node.js 22.12 или новее.

```sh
npm ci
npm run dev
```

Локальный dev: http://localhost:3001. MODX, PHP и подключение к БД для сборки не требуются.

## GitHub Pages

Адрес после успешного размещения: https://recediv.github.io/service-techmaster/

В репозитории один раз нужно выбрать **Settings → Pages → Source → GitHub Actions**. После push в main workflow собирает и проверяет весь сайт только под Томск, упаковывает его для Pages и размещает результат. Pull request выполняет сборку без публикации. Ссылка появляется в environment github-pages и завершённом deploy job.

```sh
npm run build:pages
```

Команда создаёт и проверяет полный статический экспорт в отдельном каталоге .local/build-pages-source. Затем сохраняет повторяющиеся блоки страниц один раз и сжимает их в пакеты. Итоговый каталог и точный размер записываются в .local/pages-package-report.json. Пакет больше 950 МБ не допускается к публикации. Каталог не сокращается ради лимита.

Временный просмотр использует Service Worker и встроенную распаковку gzip. Нужен актуальный браузер с JavaScript. Первое прямое открытие внутренней страницы может кратко показывать подготовку, затем открывается исходная страница. Главная доступна сразу. Dev и обычный полный статический экспорт этим механизмом не изменяются.

Просмотр закрыт от индексации. Service Worker ограничен подпапкой /service-techmaster/ и использует собственный версионный кеш. При замене этого временного размещения другим способом нужно также корректно снять его регистрацию: простое удаление файла worker не удаляет уже установленный worker у старых посетителей.

## Обычная статика и проверки

```sh
npm run check
npm run build
npm run preview
node --test scripts/pack-pages.test.mjs
```

Обычный полный экспорт находится в out/, просмотр — http://localhost:3000. Он сохраняет все HTML/RSC и существенно больше специального пакета Pages.

Исходники сайта, очищенные публичные JSON и материалы находятся в app/, components/, lib/, data/ и public/. .local/, out/, node_modules/, рабочие исследования и окружение исключены из Git.
